Google Apps Script 웹훅 URL 미등록
연동 확인된 저장 위치 드라이브에서 폴더 열기
📁 저장 대상 폴더: 내 드라이브
ID: root
1분 완성: 나만의 웹훅 URL 만드는 법
  1. script.new (Google Apps Script) 새 창 열기
  2. 기존 코드를 지우고 우측 [스크립트 복사]한 코드를 붙여넣기
  3. 코드 상단 FOLDER_ID에 저장할 구글드라이브 폴더 ID 입력
  4. 우측 상단 [배포] → [새 배포] 클릭 (코드 수정 시 반드시 [배포 관리] → [신규 버전]으로 배포)
  5. 유형: 웹 앱 선택 → 액세스 권한: 모든 사용자(Anyone) 선택 후 배포
  6. 발급된 웹 앱 URL을 복사하여 위 입력창에 넣고 [저장하기] 클릭!
